# Prompt Patterns

Use the smallest pattern that fits the deliverable. Convert bracketed fields into concrete instructions.

## Universal production prompt

1. Task: output type and its publishing purpose.
2. Subject: characters, objects, action, and factual content.
3. Composition: camera, hierarchy, panel grid, safe areas, and focal point.
4. Visual system: medium, linework, palette, materials, lighting, and background density.
5. Locked anchors: identity and design details copied verbatim across a set.
6. Exact text: literal strings, location, hierarchy, and maximum line count.
7. Output: aspect ratio, orientation, background behavior, and intended crop.
8. Constraints: prohibited additions, count limits, continuity requirements, and likely artifacts.

## Article header

- One dominant idea; avoid explaining the whole article.
- Reserve title-safe negative space when text will be added later.
- Use a strong silhouette readable at thumbnail size.
- Specify the required note header ratio supplied by the current publishing workflow; do not rely on remembered platform dimensions.

## Vertical two- or four-panel comic

- State the exact panel count and equal panel geometry.
- Define reading order from top to bottom.
- Assign one beat, action, expression, and line of dialogue to each panel.
- Lock character design across all panels.
- Keep speech short and specify balloon ownership.
- Require clean gutters and prohibit extra panels, duplicate characters, and merged scenes.

## Character sheet

- Define grid rows and columns explicitly.
- Use one character only unless the sheet is intentionally comparative.
- Include neutral front, back, left, right, and the required expressions or task poses.
- Fix scale, outfit, accessories, and lighting across cells.
- Use a plain background and generous cell margins for later slicing.

## Infographic or explainer

- Define the central claim before styling.
- Limit modules and specify their reading order.
- Provide exact labels and source-backed numbers.
- Use short callouts, visible arrows, aligned grids, and adequate type size.
- Prefer later deterministic typesetting when text density is high.

## Screenshot-style visual

- Mark it as a fictional mockup when it could be mistaken for a real post, product, or platform record.
- Specify platform-neutral layout unless exact UI reproduction is necessary and authorized.
- Avoid fabricated verification marks, engagement evidence, endorsements, or real-person statements.

## Sequential set

- Start with a shared style-and-identity block.
- List fixed anchors once, then repeat them verbatim in every generation request.
- For each image, change only shot, pose, expression, prop, and background required by the article beat.
- Preserve a numbered manifest and generate in narrative order.
